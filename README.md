# Cafe Agil POS

A Python desktop application for managing coffee shop orders and sales.

## Features

- Product catalog with prices.
- Order creation and product quantity validation.
- Automatic subtotal and total calculations.
- Graphical user interface built with Tkinter.
- MVC architecture: Model, View, and Controller.
- Sales records saved to a CSV file.

## Technologies

- Python 3
- Tkinter
- Object-oriented programming
- Model-View-Controller (MVC)
- CSV file handling

## Requirements

- Python 3
- A desktop environment with Tkinter support.

## How to Run

Run the following command from the project directory:

```bash
python cafe_agil.py
```

Sales are stored in `ventas_cafe.csv` in the working directory.

## Project Purpose

Personal programming project focused on desktop application development, object-oriented programming, and software architecture.
